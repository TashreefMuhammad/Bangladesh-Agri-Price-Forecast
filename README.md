## Overview

This repository contains:

- **AgriPriceBD dataset** — 1,779 daily retail mid-prices for five Bangladeshi agricultural commodities (July 2020 – June 2025), extracted from government PDF market reports via an LLM-assisted pipeline. *Dataset DOI to be added upon journal acceptance.*
- **Seven forecasting models** evaluated in a controlled benchmark: Naïve Persistence, SARIMA, Prophet, BiLSTM, Vanilla Transformer, T2V-Transformer, and Informer.
- **Controlled temporal encoding ablation** with Diebold-Mariano statistical significance testing comparing learnable Time2Vec embeddings against fixed sinusoidal positional encoding.
- **One reproducible notebook** (`main_experiment.ipynb`) that runs the full experiment, generates all tables and figures, and saves results to CSV.

## Key Findings

| Commodity | Best Model | MAE (BDT/kg) | Key finding |
|---|---|---|---|
| Garlic | Naïve Persistence | 5.34 | Non-stationary; BiLSTM best DL (MAE 5.87) |
| Chickpea | Naïve Persistence | 0.14 | Near-random-walk; all DL models lose to naïve |
| Green Chilli | Naïve Persistence | 1.63 | R/S 2.74; exogenous-shock dominated; T2V collapses (+75.9%) |
| Cucumber | SARIMA | 6.56 | R/S 1.62; classical methods competitive |
| Sweet Pumpkin | Naïve Persistence | 1.31 | Transformer best DL (MAE 2.76) |

**Central result:** Commodity price forecastability is structurally heterogeneous. The STL residual-to-seasonal (R/S) ratio predicts model selection better than any single model. Time2Vec learnable temporal encoding degrades on all five commodities by MAE and causes catastrophic failure on green chilli (DM stat −20.56, *p* < 0.001). Prophet fails systematically across all commodities. Informer produces erratic noise-amplifying outputs (PredVar up to 4987%) due to dataset-scale mismatch.

## Dataset (AgriPriceBD)

**AgriPriceBD** is the first publicly available daily multi-commodity retail price dataset for Bangladesh.

| Property | Value |
|---|---|
| Commodities | Garlic, Chickpea, Green Chilli, Cucumber, Sweet Pumpkin |
| Period | 22 July 2020 – 4 June 2025 |
| Observations | 1,779 per commodity |
| Price unit | BDT/kg (mid-price: average of daily min and max) |
| Source | Bangladesh government market monitoring PDF reports |
| Extraction | Gemini API (LLM-assisted bilingual structured parsing) |
| Missing data | 0.22% (4 records in green chilli; portal-outage anomaly, retained as-is) |

Each CSV has two columns:

```
date,price
2020-07-22,105.0
2020-07-23,106.5
...
```

## Models

| Model | Type | Dropout | Parameters |
|---|---|---|---|
| Naïve Persistence | Statistical | — | 0 |
| SARIMA | Statistical | — | Auto (pmdarima AIC) |
| Prophet | Statistical | — | — |
| BiLSTM | Deep learning | 0.1 / 0.3† | ~134,000 |
| Vanilla Transformer | Deep learning | 0.1 / 0.3† | ~136,000 |
| T2V-Transformer | Deep learning | 0.1 / 0.3† | ~139,000 |
| Informer | Deep learning | — | ~1.2M |

†Dropout 0.3 applied to green chilli and sweet pumpkin for all three DL models (0.1 otherwise).

**Ablation design:** `Transformer` and `T2V-Transformer` are architecturally identical — only the temporal encoding layer differs (fixed sinusoidal PE vs. learnable Time2Vec). All other components (d_model=64, 4 heads, 2 Pre-LN encoder layers, d_ff=256, 90-day window, 14-day horizon) are held constant. This cleanly isolates the temporal encoding contribution.

## Why These Design Choices?

**Why is Informer excluded from the main comparison table?**
Informer's ProbSparse attention and distilling convolutions were designed for sequences with
10,000+ observations. On 90-step windows from ~1,400 training windows, two distilling layers
reduce the effective representation to 22 positions, producing degenerate attention patterns
that amplify noise (chickpea PredVar 4987%). It is evaluated separately and documented as a
negative result to guide practitioners.

**Why did Time2Vec fail?**
On high-noise commodities (green chilli R/S = 2.74), learnable temporal parameters overfit to
spurious periodicities in the training period. On near-random-walk commodities (chickpea
R/S = 0.43), there is no periodic structure for Time2Vec to discover. The Newey-West variance
estimator goes negative for chickpea and green chilli due to strong loss-differential
autocorrelation; a conservative fallback to unconditional variance is used and reported with †.

**Why d_model=64?**
~1,780 daily observations is a small training set. Keeping the model small (< 200K parameters)
prevents overfitting and allows reasonable runtimes on Colab free tier.

**Why not walk-forward validation?**
The 5-year dataset makes a strict single temporal split the maximum-data-efficiency choice.
Walk-forward validation over multiple windows is recommended for future work when the dataset
is extended.
